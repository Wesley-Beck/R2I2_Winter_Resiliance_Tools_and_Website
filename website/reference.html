Table 1. Climate Dataset Variable Availability and Fire Danger Index Capability

Summary of 16 climate datasets evaluated for wildfire risk analysis in the Western Upper Peninsula of Michigan. Variable availability determines which Fire Danger Index (FDI) systems each dataset can support. The Canadian Fire Weather Index (FWI) and National Fire-Danger Rating System (NFDRS) require temperature, relative humidity, wind speed, and precipitation. The Fire Potential Index (FPI) requires only temperature and relative humidity. Datasets are grouped by type: reanalysis products, station-interpolated gridded observations, radar/satellite-derived products, and climate model projections.

Dataset Type Spatial Temporal Period Climate Variables FDI Capability
T RH W P R SP FWI NFDRS FPI
T = Temperature; RH = Relative Humidity (or derivable from dewpoint/vapor pressure); W = Wind Speed; P = Precipitation; R = Radiation (SW/LW); SP = Surface Pressure. FWI = Canadian Fire Weather Index System (Van Wagner 1987); NFDRS = National Fire-Danger Rating System (Bradshaw et al. 1984); FPI = Fire Potential Index (Burgan et al. 1998).
Table 2. AORC v1.1 Input Data Sources by Variable and Time Period

The NOAA Analysis of Record for Calibration (AORC) v1.1 dataset integrates observations from multiple sources that change over the 1979–present record. Precipitation sources transition from satellite-based estimates to gauge-calibrated NEXRAD radar. Non-precipitation forcing transitions from global reanalysis (GDAS/MERRA-2) to high-resolution mesoscale analysis (URMA). After Fall et al. (2023).

Period Precipitation Source Non-Precip Forcing Resolution Notes
1979 – 1994 Stage II + CMORPH satellite QPE GDAS / MERRA-2 reanalysis ~800 m Pre-NEXRAD era. Satellite-derived precipitation estimates.
1995 – 2001 NEXRAD Stage II hourly GDAS / MERRA-2 reanalysis ~800 m Early NEXRAD deployment. Stage II radar precipitation.
2002 – 2015 Stage IV gauge-calibrated NEXRAD GDAS / MERRA-2 reanalysis ~800 m High-quality radar+gauge blend. RFC mosaicked product.
2016 – 2017 Stage IV gauge-calibrated NEXRAD NLDAS-2 to URMA transition ~800 m Transition period. Non-precip forcing migrates to URMA.
2018 – present Stage IV gauge-calibrated NEXRAD URMA reanalysis (2.5 km) ~800 m Current era. Highest quality forcing from mesoscale analysis.
AORC = Analysis of Record for Calibration; QPE = Quantitative Precipitation Estimate; NEXRAD = Next-Generation Radar; GDAS = Global Data Assimilation System; MERRA-2 = Modern-Era Retrospective analysis for Research and Applications; URMA = UnRestricted Mesoscale Analysis; RFC = River Forecast Center. Source: Fall et al. (2023), JAWRA.
Table 3. Fire Danger Index System Variable Requirements

Minimum input variables required by each Fire Danger Index system implemented in this study. Additional variables (e.g., radiation, fuel type) improve accuracy but are not strictly required.

FDI System Required Variables Optional / Improves Output Indices Reference
Canadian FWI Temperature, Relative Humidity, Wind Speed, Precipitation Day length (latitude-derived) FFMC, DMC, DC, ISI, BUI, FWI Van Wagner (1987)
NFDRS Temperature, Relative Humidity, Wind Speed, Precipitation Radiation (SW/LW), fuel model, slope, aspect FM1, FM10, FM100, FM1000, SC, ERC, BI Bradshaw et al. (1984)

Data Access

  • AORC v1.1: s3://noaa-nws-aorc-v1-1-1km (Zarr, open access via AWS NODD)
  • ERA5 / ERA5-Land: s3://era5-pds (AWS) or Copernicus Climate Data Store API
  • HRRR: s3://noaa-hrrr-bdp-pds (GRIB2) or s3://hrrrzarr (Zarr)
  • Daymet v4: s3://daymet-v4-na (AWS Open Data) or ORNL DAAC THREDDS
  • GridMET: Climatology Lab HTTP download or Google Earth Engine
  • NEX-GDDP-CMIP6: s3://nex-gddp-cmip6 (NASA, 27 GCMs, SSP2-4.5 / SSP5-8.5)
  • ClimRR: Argonne National Laboratory ArcGIS Feature Service or download portal
  • GLARM: Michigan Technological University GLARM project data portal
